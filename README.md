# 생성형 AI에게 데이터를 "제대로" 시키는 법 🤖📊

> **논문 더미에서 메타분석용 숫자를 자동으로 캐내는 프롬프트 설계 이야기**
> — 디지털 미술치료 메타분석 프로젝트에서 실제로 쓴 10단계 프롬프트를 뜯어보며 배우는, "LLM 구조화 데이터 추출(Structured Data Extraction)" 완전 입문

---

## 🎯 이 글이 답하는 질문

> **"AI에게 '논문에서 숫자 좀 정리해줘'라고 했더니 매번 다르게 나와요. 어떻게 하면 정확하고 일관되게 뽑을 수 있죠?"**

이 글을 다 읽으면 당신은:
- ✅ AI가 **왜** 들쭉날쭉한 답을 주는지 이해하고
- ✅ **신뢰할 수 있는** 데이터 추출 프롬프트를 직접 설계할 수 있고
- ✅ "원본 → 정제 → 최종" 같은 **검증 가능한** 파이프라인을 만들 수 있습니다.

대상: 메타분석·체계적 문헌고찰을 하는 대학원생, LLM으로 데이터를 뽑으려는 모든 연구자.

---

## 1. 먼저, 나쁜 예시부터 봅시다 😱

당신이 AI에게 이렇게 말했다고 합시다:

> 🗣️ "이 논문에서 실험군이랑 통제군 점수 좀 정리해줘."

그러면 이런 일이 벌어집니다:

| 1번째 실행 | 2번째 실행 | 3번째 실행 |
|---|---|---|
| 표로 정리해줌 | 줄글로 설명해줌 | "분산"을 줬는데 "표준편차"라고 적음 |
| 사전/사후 구분 ✅ | 사전/사후 섞임 ❌ | 통제군 빠뜨림 ❌ |

**같은 논문, 같은 AI인데 결과가 매번 다릅니다.** 메타분석에서 이건 치명적이에요. 숫자 하나가 효과크기를 바꾸고, 결론을 바꾸니까요.

왜 이럴까요? AI가 멍청해서가 아닙니다. **당신이 "무엇을, 어떻게, 어떤 모양으로" 달라고 말해주지 않았기 때문**입니다.

---

## 2. 핵심 비유: AI는 "똑똑하지만 오늘 처음 출근한 인턴"이다 👔

이 한 문장만 기억하세요. 이게 이 글 전체의 핵심입니다.

생성형 AI는 **엄청나게 똑똑하지만, 당신의 연구 맥락은 하나도 모르는, 오늘 처음 온 인턴**과 같습니다.

똑똑한 인턴에게 일을 잘 시키려면 어떻게 하나요?

| 인턴에게 하는 일 | = 프롬프트에서 하는 일 |
|---|---|
| 1. "너는 데이터 정리 담당이야" 역할 지정 | **역할 부여 (Persona)** |
| 2. "이런 자료만 가져와" 기준 설명 | **선별 규칙 (Inclusion/Exclusion)** |
| 3. "이 양식에 맞춰 채워" 템플릿 제공 | **출력 형식 고정 (Schema)** |
| 4. "이 표 보고 모르면 찾아봐" 참고자료 | **레퍼런스 주입 (Reference)** |
| 5. "계산은 이 공식대로 해" 공식 명시 | **명시적 변환 규칙 (Formula)** |
| 6. "중간 계산 과정도 적어둬" | **단계 분해 (Decomposition)** |
| 7. "딴말 말고 양식만 줘" | **출력 통제 (Constraints)** |

우리가 볼 10단계 프롬프트는 **정확히 이 7가지를 하고 있습니다.** 하나씩 보겠습니다.

---

## 3. 우리의 실전 미션 🎬

**상황**: 디지털 미술치료 논문 수십 편이 있다. 각 논문에서 메타분석에 쓸 숫자를 뽑아야 한다.

**뽑아야 하는 것** — 딱 이 조합입니다:

```
        사전(pre)        사후(post)
실험군   평균, 표준편차    평균, 표준편차
통제군   평균, 표준편차    평균, 표준편차
```

**문제는?** 논문마다 보고 방식이 제각각입니다:
- 어떤 논문은 1~5 척도, 어떤 논문은 1~7 척도
- 어떤 논문은 "분산"을, 어떤 논문은 "표준편차"를 보고
- 어떤 논문은 사후 점수 대신 **변화량(Δ)**만 줌
- "스트레스"처럼 높을수록 **나쁜** 점수와, "행복"처럼 높을수록 **좋은** 점수가 섞임

→ 이 난장판을 **하나의 통일된 형식**으로 바꿔야 비교가 가능합니다. 이게 AI가 할 일이에요.

## 4. 10단계 프롬프트 해부 🔬

각 단계를 "인턴 교육 한 토막"으로 읽어보세요.

### [1단계] 논문 기본정보 — *"먼저 이름표부터 달자"*
논문명·저자·발행년도. 가장 쉬운 것부터 시작해 AI의 "워밍업"을 시킵니다.

### [2단계] 선별 규칙 — *"이런 것만 가져와, 저런 건 버려"*
```
✅ 가져올 것: 실험군 + 통제군 둘 다 있고, 사전·사후 평균·SD가 다 있는 척도
❌ 버릴 것:  통제군 없음 / 값 빠짐 / 변화량(Δ)만 덜렁 있음
```
💡 **교훈**: "뭘 가져올지"만큼 **"뭘 버릴지"**를 명확히 말해야 AI가 헛것을 주워오지 않습니다.

### [3단계] 계층 구조 — *"큰 상자 안의 작은 상자들"*
척도는 종종 **상위척도 ⊃ 하위요인** 구조입니다.

> 🎨 예: **삶의 질(FACT-G)** 이라는 큰 척도 안에
> └ 신체 상태(7문항), 사회/가족(7문항), 정서(6문항), 기능(7문항)

이런 건 하위요인 하나하나를 **따로** 뽑고(계층=1), 큰 척도도 따로 표시(계층=2)합니다.

### [4단계] 원본 데이터 입수 — *"논문에 적힌 그대로, 손대지 말고"*
이 단계의 철칙: **절대 가공하지 않는다.** 논문에 있는 숫자를 그대로 베낍니다.
- 단, **변화량(Δ)의 방향**만은 확인: "사후-사전"인지 "사전-사후"인지. 부호가 반대면 결과가 뒤집힙니다!

### [5단계] 레퍼런스 문항수 표 — *"모르면 이 커닝페이퍼를 봐"* 📑
이게 **신의 한 수**입니다. AI에게 유명 척도들의 "정답표"를 미리 줍니다:

> - Rosenberg 자아존중감 척도(RSES): **10문항, 1~4 리커트, 부정문항 5개 역채점**
> - 지각된 스트레스 척도(PSS-10): **10문항, 0~4 리커트, 긍정문항 4개 역채점**
> - ... (10개 척도)

💡 **교훈**: 논문에 문항수가 안 적혀 있어도, AI가 **추측(=환각)하지 않고** 이 표에서 찾습니다. **"모르면 지어내지 말고 여기서 찾아"** 가 환각을 막는 핵심입니다.

### [6단계] 정제값 필드 — *"중간 정리칸"*
원본을 다듬은 값을 담는 칸. (※ 작동 원리상 [7단계] 계산 결과가 여기 들어옵니다.)

### [7단계] 정제 과정 — *"이제 다듬자"* 🧹
여기서 실제 변환이 일어납니다 (자세한 건 5장에서):
- 문항수·척도범위 보정 / 분산→SD / Δ복원 / 역채점 / 방향성 기록

### [8단계] 최종 산출 — *"모두 같은 자로 재자"* 📏
모든 척도를 **1~5로 통일**하고, 상위척도를 하위요인으로부터 재계산합니다.

### [9단계] 출력 JSON 구조 — *"이 양식에 정확히 채워"*
빈칸이 다 그려진 양식(템플릿)을 통째로 줍니다. AI는 빈칸만 채우면 됩니다.

### [10단계] 처리 요약 — *"마지막으로 체크리스트 점검"*
지금까지 한 일을 한 번 더 정리시켜, AI 스스로 빠뜨린 게 없는지 확인하게 합니다.

## 5. 다섯 가지 "마법 같은" 변환 ✨ (예시 중심)

여기가 제일 재밌는 부분입니다. 각 변환을 **실제 숫자**로 따라가 봅시다.

### 변환 ① Δ복원 — "출발점 + 이동거리 = 도착점" 🏃
논문이 **사전 점수**와 **변화량(Δ)**만 줬을 때, 사후 점수를 복원합니다.

```
사전 평균 = 3.0,  Δ = +0.5
→ 사후 평균 = 3.0 + 0.5 = 3.5  ✅

표준편차는? 그냥 더하면 안 됩니다! 제곱해서 더하고 다시 루트:
사전 SD = 0.4,  Δ의 SD = 0.3
→ 사후 SD = √(0.4² + 0.3²) = √(0.16+0.09) = √0.25 = 0.5  ✅
```
💡 왜 SD는 제곱해서 더할까요? **분산(=SD²)이 더해지는 양**이기 때문입니다. ("피타고라스 정리"를 떠올리세요 📐)

### 변환 ② 분산 ↔ 표준편차 — "단위 맞추기" 🔁
논문이 분산(Variance)을 보고했다면 표준편차로 바꿉니다.
```
분산 = 0.64  →  SD = √0.64 = 0.8  ✅
```
🚨 **흔한 실수**: 분산 0.64를 그냥 SD 0.64로 적기. 이러면 효과크기가 완전히 틀어집니다.

### 변환 ③ 척도 통일 — "달러와 유로를 원화로 환전" 💱
1~7 척도와 1~5 척도는 **그냥 비교하면 안 됩니다.** 환율 환전하듯 다 1~5로 바꿉니다.

```
1~7 척도에서 평균 5.0점을 1~5로:
X′ = 1 + (5.0 − 1) × (4/6) = 1 + 4 × 0.667 = 3.67  ✅
SD′ = SD × (4/6)   (예: SD 1.2 → 0.8)
```
| 원래 척도 | 변환 공식 |
|---|---|
| 1~7 → 1~5 | X′ = 1 + (X−1)×(4/6) |
| 0~4 → 1~5 | X′ = 1 + X |
| 1~4 → 1~5 | X′ = 1 + (X−1)×(4/3) |
| 1~5 | 그대로 (변환 불필요) |

### 변환 ④ 역채점 — "꼴찌 등수를 점수로 뒤집기" 🔄
"스트레스", "우울"처럼 **높을수록 나쁜** 척도는, **높을수록 좋게** 방향을 뒤집어야 다른 척도와 같은 방향이 됩니다.

```
1~5 척도 스트레스, 평균 4.0 (높아서 나쁨)
→ 역채점: (최댓값 + 최솟값) − 평균 = (5 + 1) − 4.0 = 2.0  ✅
   이제 "2.0" = 스트레스가 낮음 = 좋음.  방향이 통일됨!
표준편차는 그대로 유지 (뒤집어도 퍼진 정도는 안 변함)
```
💡 **왜 필요?** 메타분석은 효과크기를 합칩니다. 어떤 척도는 "↑=좋음", 어떤 건 "↑=나쁨"이면, 양수·음수가 뒤섞여 평균이 엉망이 됩니다. **모두 "↑=좋음"으로 정렬**해야 합니다.

### 변환 ⑤ 상위척도 합성 — "부분 점수로 전체 점수 만들기" 🧩
하위요인들의 값으로 상위척도를 계산합니다.

```
하위요인 평균: 3.0, 4.0, 5.0
→ 상위 평균 = (3.0 + 4.0 + 5.0) / 3 = 4.0  ✅  (단순 산술평균)

하위요인 SD: 0.5, 0.6, 0.7  (하위요인 3개)
→ 상위 SD = √(0.5² + 0.6² + 0.7²) / 3
          = √(0.25 + 0.36 + 0.49) / 3
          = √1.10 / 3 = 1.0488 / 3 = 0.35  ✅
```

> ⚠️ **여기서 통계적으로 중요한 함정!** (실제로 이 프로젝트에서 잡아낸 버그)
>
> 처음엔 `상위SD = √(하위 SD²의 평균)` = √(1.10/3) = **0.61** 로 잘못 썼었습니다.
> 올바른 식은 `√(하위 SD²의 합) / 하위요인수` = √1.10 / 3 = **0.35** 입니다.
>
> **차이의 핵심: "분산은 평균내는 게 아니라, 더한 뒤 (요인수)²로 나눈다."**
> `(X+Y)/2`의 분산은 `(Var X + Var Y)/4` 이지 `(Var X + Var Y)/2`가 아니니까요.
> (※ 이 식은 하위요인 간 상관이 0이라는 가정. 상관이 있으면 공분산 항이 더 붙습니다 — 6장 참고.)

## 6. "원본 → 정제 → 최종": 영수증처럼 계산 과정을 다 보여줘 🧾

이 프롬프트의 가장 영리한 설계는 **모든 숫자를 3번 적게 하는 것**입니다.

```
원본실험집단사전평균 : 5.0    ← 논문 그대로
정제실험집단사전평균 : 5.0    ← Δ복원·분산변환 후
최종실험집단사전평균 : 3.67   ← 1~5로 통일 후
```

왜 이렇게 귀찮게 할까요?

1. **검산 가능** 🔍 — 최종값이 이상하면 어느 단계에서 틀렸는지 역추적할 수 있습니다.
2. **AI의 정확도 ↑** — "한 방에 답을 내"라고 하면 AI는 중간 계산을 건너뛰고 틀립니다. **계산 과정을 펼쳐서 적게 하면(=Chain of Thought) 정확도가 올라갑니다.**
3. **재현성** ♻️ — 다른 사람이 봐도 "아, 이렇게 변환했구나"를 알 수 있습니다.

💡 **교훈**: AI에게 어려운 계산을 시킬 땐, **"답만 줘"가 아니라 "과정을 단계별로 보여줘"** 라고 하세요. 인간이 암산보다 필산이 정확한 것과 똑같습니다.

## 7. 왜 하필 JSON으로 받나? 그리고 "순수 JSON 강박" 📦

프롬프트는 강박적으로 반복합니다: **"마크다운·설명문·주석 절대 금지, 순수 JSON만."**

이유는 단순합니다. 이 출력을 **사람이 읽는 게 아니라 다음 프로그램이 읽기** 때문입니다.

```python
data = json.loads(gpt_response)   # ← 여기서 AI가 "네, 정리했습니다! ```json {...}```"
                                  #    이라고 친절하게 답하면 즉시 에러 💥
```

AI는 친절하게 설명을 덧붙이려는 습성이 있는데, 그 친절이 프로그램을 망가뜨립니다. 그래서 **"기계가 먹을 거니까 인사말 빼고 데이터만"** 이라고 못 박는 겁니다.

💡 **교훈**: 출력을 코드가 받을 거면, **형식을 극단적으로 엄격하게** 지정하세요. 예시 양식(9단계의 빈 템플릿)을 통째로 주는 게 가장 확실합니다.

## 8. 흔한 함정 모음 😱 (체크리스트)

| 함정 | 증상 | 처방 |
|---|---|---|
| 🕳️ 분산을 SD로 착각 | 효과크기가 이상하게 큼 | "분산이면 √ 씌워라" 명시 |
| 🕳️ Δ 부호 반대 | 효과 방향이 뒤집힘 | "사전-사후인지 사후-사전인지 확인" |
| 🕳️ 역채점 누락 | 어떤 척도만 음수 효과 | 부정척도 목록 + 역채점식 제공 |
| 🕳️ 척도 안 맞춤 | 1~7과 1~5를 그냥 합침 | 전부 1~5로 환산 |
| 🕳️ 분산을 평균냄 | 상위척도 SD가 과대 | √(SD²합)/k 로 (더한 뒤 k로 나눔) |
| 🕳️ AI가 문항수 지어냄 | 출처 불명 숫자 | 레퍼런스 표 주입, "모르면 공란" |
| 🕳️ JSON에 인사말 섞임 | `json.loads` 에러 | "순수 JSON만" 반복 명시 |

## 9. 직접 해보기 🛠️ (미니 실습)

아래 가짜 논문 한 줄을 AI에게 주고, 우리 원칙대로 뽑아보세요.

> **연습 문제**:
> *"실험군(n=20)은 지각된 스트레스(PSS-10, 0~4 척도)가 사전 평균 2.8(SD 0.5)에서 사후 2.0(SD 0.4)으로 감소했다. 통제군(n=20)은 사전 2.7(SD 0.5), 사후 2.6(SD 0.5)이었다."*

<details>
<summary>👉 정답 보기 (직접 풀어본 뒤 펼치세요)</summary>

1. **선별**: 실험·통제군 둘 다 있고 사전·사후 평균·SD 다 있음 → ✅ 포함
2. **역채점**: 스트레스 = 부정척도. 0~4 척도라 (4+0)−평균.
   - 실험 사전: 4−2.8 = 1.2 / 사후: 4−2.0 = 2.0 (이제 ↑=좋음)
3. **척도 통일** (0~4 → 1~5: X′ = 1 + X):
   - 실험 사전: 1+1.2 = 2.2 / 사후: 1+2.0 = 3.0
   - SD는 그대로 (0~4→1~5는 폭이 같아 SD 불변)
4. **해석**: 실험군은 2.2→3.0으로 (역채점·통일 후) 스트레스가 개선, 통제군은 거의 변화 없음.

→ 이렇게 **"같은 자(1~5)·같은 방향(↑=좋음)"** 으로 맞춰야 비로소 다른 논문과 합칠 수 있습니다.
</details>

## 10. 핵심 교훈 10가지 📌 (한 장 요약)

생성형 AI로 데이터를 추출할 때 기억할 것:

1. **AI는 똑똑한 인턴이다.** 맥락을 모른다고 가정하고 다 설명하라.
2. **역할을 줘라.** "너는 ○○ 전문가다"가 출력 품질을 바꾼다.
3. **가져올 것 + 버릴 것**을 둘 다 명시하라.
4. **출력 양식을 통째로 줘라.** 빈칸 채우기가 가장 안정적이다.
5. **"순수 JSON만"** — 기계가 먹을 거면 인사말을 막아라.
6. **공식을 직접 줘라.** AI의 즉흥 계산을 믿지 마라.
7. **커닝페이퍼(레퍼런스)를 줘라.** "모르면 지어내지 말고 찾아."
8. **과정을 펼치게 하라.** 원본→정제→최종, 답보다 과정.
9. **방향·부호·단위**가 가장 자주 틀린다. 콕 집어 경고하라.
10. **검증 칸을 만들어라.** AI가 자기 일을 스스로 점검하게 하라.
