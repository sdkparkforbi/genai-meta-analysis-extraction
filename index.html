The Magic

다섯 가지 "마법 같은" 변환 ✨

실제 숫자로 따라가 봅시다. 여기가 핵심입니다.

① Δ복원 — "출발점 + 이동거리 = 도착점" 🏃

사전 점수 + 변화량(Δ)만 줬을 때 사후를 복원
사전 3.0+Δ +0.5 →사후 3.5

SD는 더하면 안 됨! √(0.4² + 0.3²) = √0.25 = 0.5 · 분산이 더해지니까(피타고라스 📐)

② 분산 ↔ 표준편차 — "단위 맞추기" 🔁

논문이 분산을 보고했다면 SD로
분산 0.64→ √SD 0.8

🚨 분산 0.64를 그냥 SD 0.64로 적으면 효과크기가 완전히 틀어집니다.

③ 척도 통일 — "달러·유로를 원화로 환전" 💱

1~7 과 1~5 는 그냥 비교 불가 → 모두 1~5로
1~7 척도 · 5.0→ 1+(5−1)×4/6=3.67

1~7→1~5: X′=1+(X−1)×4/6 · 0~4→1~5: X′=1+X · 1~4→1~5: X′=1+(X−1)×4/3

④ 역채점 — "꼴찌 등수를 점수로 뒤집기" 🔄

"스트레스↑=나쁨"을 "↑=좋음"으로 방향 통일
스트레스 4.0→ (5+1)−4.0=2.0

왜? 메타분석은 효과를 합칩니다. 방향이 섞이면 양수·음수가 상쇄돼 엉망 → 모두 "↑=좋음"으로 정렬. SD는 그대로.

⑤ 상위척도 합성 — "부분 점수로 전체 만들기" 🧩

하위요인 값으로 상위척도 계산
하위 평균 3·4·5→ 평균4.0
하위 SD 0.5·0.6·0.7→ √(0.25+0.36+0.49)/3=0.35

⚠️ 핵심 함정: 분산은 평균내는 게 아니라, 더한 뒤 요인수로 나눈다. `(X+Y)/2`의 분산은 (Vx+Vy)/4이지 (Vx+Vy)/2가 아님. (상관 0 가정 — 양의 상관이면 공분산 항 추가)

Watch Out

흔한 함정 모음 😱

분산을 SD로 착각 — 효과크기가 과대 → "분산이면 √ 씌워라"
Δ 부호 반대 — 효과 방향 뒤집힘 → "사전-사후/사후-사전 확인"
역채점 누락 — 어떤 척도만 음수 → 부정척도 목록 제공
척도 안 맞춤 — 1~7과 1~5 혼합 → 전부 1~5
분산을 평균냄 — 상위 SD 과대 → √(SD²합)/k
AI가 문항수 지어냄 — 출처불명 → "모르면 공란"
Takeaways

핵심 교훈 10가지 📌

  1. AI는 똑똑한 인턴이다. 맥락을 모른다고 가정하라.
  2. 역할을 줘라. "너는 ○○ 전문가다".
  3. 가져올 것 + 버릴 것을 둘 다 명시하라.
  4. 출력 양식을 통째로 줘라(빈칸 채우기).
  5. "순수 JSON만" — 기계가 먹을 거면 인사말 막아라.
  6. 공식을 직접 줘라. 즉흥 계산을 믿지 마라.
  7. 커닝페이퍼를 줘라. "모르면 찾아."
  8. 과정을 펼치게 하라. 답보다 과정.
  9. 방향·부호·단위가 가장 자주 틀린다.
  10. 검증 칸을 만들어 AI가 스스로 점검하게 하라.
