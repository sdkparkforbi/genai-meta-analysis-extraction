# 메타분석 데이터 추출 — 10단계 프롬프트 전문

> 실제 `ask_gpt_for_data_extraction()` 함수에서 GPT-4o에 전달하는 프롬프트입니다.
> 자신의 분야에 맞게 **[5단계] 레퍼런스 표**와 **변환 공식**을 바꿔 쓰세요.

```text
당신은 심리측정 데이터 구조화 전문가입니다.
첨부된 논문으로부터 실험집단과 통제집단 모두의 사전·사후 평균 및 표준편차(또는 분산)
정보가 명시적으로 제시된 척도만 선별하여, 아래 10단계 절차에 따라 완전한 JSON 형식으로
출력하십시오. 응답은 반드시 순수 JSON 객체만 포함하며, 마크다운·설명문·주석·구분선은
절대 포함하지 않습니다.

[1단계] 논문 기본정보
- 논문명 / 저자(쉼표 구분) / 발행년도(4자리)

[2단계] 척도 선별 및 제외 규칙
2.1 포함: 실험·통제집단 모두 존재 + 두 집단 모두 사전·사후 평균·SD(또는 분산) 명시
2.2 배제: 통제집단 부재 / 사전·사후 결측 / 사전값 없이 Δ만 존재

[3단계] 계층 구조 처리
- 총_계층수, 현재_계층(하위요인=1, 전체척도=2+)
- 하위요인 존재 시 각각 별도 scale 객체로 출력

[4단계] 원본데이터입수과정
- 논문 수치 그대로 입력, 미기재는 공란
- Δ 존재 시: ①사후-사전 / 사전-사후 확인 ②사전-사후면 부호 반전
- 데이터출처·원본방향성(높을수록 긍정/부정) 명시

[5단계] 레퍼런스 문항수 표   ← 분야에 맞게 교체할 부분
- Rosenberg(1965) RSES: 10문항, 1~4 리커트, 부정문항 5개 역채점
- Cohen 등(1983) PSS-10: 10문항, 0~4 리커트, 긍정문항 4개 역채점
- Neff(2003) SCS: 26문항, 1~5 리커트, 6하위요인, 부정문항 역채점
- (… 분야별 주요 척도 목록 …)

[6단계] 정제값 필드
- [7단계]에서 보정된 문항수·척도범위를 반영한 값 입력
- 정제문항수·정제척도범위·정제방향성 포함

[7단계] 원본데이터정제과정
7.1 문항수·척도범위 보정 (없으면 레퍼런스 표 참조, 허구문항 차감)
7.2 Δ복원: 사후=사전+Δ, 사후SD=√(사전SD² + ΔSD²)
7.3 수치 변환: 분산→SD = √Var, 합산평균→문항평균 = 평균/문항수
7.4 역채점: 부정척도는 (최댓값+최솟값) − 평균, SD 유지
7.5 하위척도는 각각 독립 기록 (상위는 최종단계에서 재산출)
7.6 정제방향성 필드에 명시

[8단계] 최종데이터산출과정
8.1 척도범위 1~5 통일
    1~7→1~5: X′=1+(X−1)×(4/6),  SD′=SD×(4/6)
    0~4→1~5: X′=1+X,            SD′=SD
    1~4→1~5: X′=1+(X−1)×(4/3),  SD′=SD×(4/3)
8.2 상위항목 계산
    상위평균 = 하위요인 평균들의 산술평균
    상위SD   = √(하위요인 SD²의 합) / 하위요인수     ← 분산 가법성 기반(상관 0 가정)
    상위문항수 = 하위요인 문항수 합산
8.3 방향성 유지 확인 (최종방향성 필드 포함)
```

## 설계 포인트 한눈에 보기

| 단계 | 프롬프트 엔지니어링 기법 |
|---|---|
| 도입부 | 역할 부여 + 출력 형식 강제 |
| 1~2단계 | 선별/제외 규칙 (노이즈 제거) |

## ⚠️ 통계 노트: 상위척도 SD

```
상위SD = √(하위요인 SD²의 합) / 하위요인수
```
이는 `T = (1/k)·Σ Xⱼ` 의 분산 `Var(T) = (1/k²)·Σ Var(Xⱼ)` 에서 온 식으로,
**하위요인 간 상관이 0**이라는 가정 하에 정확합니다.

하위요인이 양의 상관을 가지면 공분산 항이 추가됩니다:

```
상위SD = (1/k)·√( Σ SDⱼ² + 2·Σ rⱼₗ·SDⱼ·SDₗ )
```

엄밀한 합성이 필요하면 상관 r을 가정해 민감도 분석을 하거나
(Borenstein et al., 2009, *Introduction to Meta-Analysis*),
하위요인별 효과크기를 따로 산출 후 종속성을 고려해 합성하는 편이 좋습니다.
